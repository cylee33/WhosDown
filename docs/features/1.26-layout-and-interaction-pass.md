## Rules and edge cases

1. Spacing values come only from `DesignSystem` tokens (4, 8, 16, 24, 32, 48); no raw numbers in views.
2. Colors come only from tokens; status colors only from `StatusBadge`.
3. Sheets: drag handle, title, one-line explanation, main action on top (red if destructive), secondary below. Use medium height when the content fits.
4. Wording: "Match" not "game", "Host" not "organizer" (D13); sentence case for buttons as in the wireframes.
5. Every button that runs a network call shows progress and can't be tapped twice.
6. Every list has an empty state; every network action has a plain-language error.
7. **Basic accessibility** (part of the audit): every screen works at the largest Dynamic Type size, and every icon-only button has a VoiceOver label. Fuller accessibility is a V2 objective (plan §9).
