## Goal

For an outdoor Match, show the forecast for its start hour in one short line, like "64°F · Clear · 8% rain".

## Screens

| Screen | What this feature owns on it |
|---|---|
| H09, H14 | Weather line next to the Venue line ("64°F · Clear · Outdoor") |
| H18, H19 | Weather card in Create Match ("64°F · Clear · 8% rain", "Outdoor event") |

## Data

| Source | Call |
|---|---|
| Open-Meteo | `GET https://api.open-meteo.com/v1/forecast?latitude=…&longitude=…&hourly=temperature_2m,weather_code,precipitation_probability&temperature_unit=fahrenheit&timezone=auto&forecast_days=16`. No key |

## Rules and edge cases

1. Only for outdoor Matches (`isIndoor == false`). Indoor Matches show "Indoor" and no forecast.
2. Use the forecast hour closest to `startTime`.
3. Open-Meteo forecasts 16 days ahead. Further out, hide the line.
4. Text: temperature rounded to whole °F, a condition word from the WMO weather code (Clear, Partly cloudy, Cloudy, Fog, Drizzle, Rain, Snow, Thunderstorm), and rain chance when 10% or more.
5. Cache results per location (rounded to 2 decimals) for 30 minutes, so lists don't repeat calls.
6. Network failure or bad data hides the line. Never show an error for weather.
7. Ended Matches show no weather.
