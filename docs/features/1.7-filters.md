## Goal

A Player narrows Discover by sport, time, distance, skill level, and join type. Their distance is remembered.

| Screen | What this feature owns on it |
|---|---|
| H08 Filters | Bottom sheet over the map: sport, time (Now / Tonight / Tomorrow / custom range), distance typed in miles, skill level, join type; button "Show N Matches"; "Reset" |

## Rules and edge cases

1. **Sport:** multi-select from the nine sports plus Other. None selected means all.
2. **Time** (one choice, or none for any time):
   - **Now:** started and not ended, or starting within the next hour.
   - **Tonight:** starts today between 5:00 PM and midnight.
   - **Tomorrow:** starts any time tomorrow.
   - **Custom:** the Player picks the **days** (a date range, from–to) and a **time of day** window (for example 5:00 PM–9:00 PM). A Match matches if it starts on one of those days inside that window. Either part can be left as "Any".
3. **Distance:** typed in miles, 0.5–25, one decimal. Saved to settings; Guests' value lasts only for the session.
4. **Skill level:** multi-select. A Match marked All Levels matches every skill choice.
5. **Join type:** Any / Open / Approval required.
6. The button shows the live count: "Show 4 Matches".
7. Sport, time, skill, and join type last for the app session; only distance is saved.
8. "Reset" clears everything except distance.
9. The number of active filters shows on the "Filters N" chip (1.6) and the map's filter icon.
