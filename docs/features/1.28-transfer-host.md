## Rules and edge cases

1. Only to an approved Player in this Match (D33).
2. Takes effect at once; no accept step (D33).
3. The former Host stays as an approved Player and can then leave normally (1.16).
4. The new Host gets an in-app notification that opens H20.
5. The Host label in Match chat moves (1.20; no write).
6. Allowed until the Match ends, so a Host who couldn't come can hand over check-in (1.27).
7. With no approved Players: the sheet says "No Players to transfer to yet. You can cancel the Match instead."
8. Pending Join requests and the waitlist stay as they are; the new Host handles them.
9. Reminders: the former Host keeps theirs (still approved); the new Host already has one.
