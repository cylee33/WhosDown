## Goal

A Player sees every important change about their Matches in one list, with an unread count, and each item opens the right screen.

## Screens

| Screen | What this feature owns on it |
|---|---|
| Notifications list (H50 style) | One list replacing H31 + H50: type badge, title, body, time ago; unread items bold; swipe to delete |
| Bell (no frame) | Bell icon with unread count in the Discover and Matches nav bars; opens the list |
| H51 Match updated | "UPDATED" header, title "Pickup Soccer changed location", time; "What changed": old → new per field; Host note; "View updated Match"; "Open Match chat"; "You'll stay approved — no RSVP action needed." |
| H52 Match cancelled | Red header, Match title, Host's reason; "Your RSVP: your spot was released automatically."; "Find similar Matches" |

Leave out "Settings" (H32, V2), "Message organizer" on H52 (direct messages, V2), and the V2 types.

## Data

| ID | Read / write | Path and fields |
|---|---|---|
| R10 | read (listener) | `users/{me}/notifications` ordered by `createdAt` desc, last 50 |
| W17 | write | `isRead = true` when opened; delete on swipe |

**V1 types:** `approved`, `declined`, `matchUpdated`, `matchCancelled`, `spotOpened` (to the Host), `hostTransferred`. No `spotOpen` and no H53 (ADR-0008).

## Rules and edge cases

1. Badge colors: approved green, declined red, updated blue, cancelled red, spot opened orange, transferred green.
2. Tapping an item marks it read and opens:
   - approved → Match details showing H14
   - declined → H35
   - matchUpdated → H51
   - matchCancelled → H52
   - spotOpened → H21 (Join requests and Waitlist)
   - hostTransferred → H20
3. The unread count counts `isRead == false`; it updates live.
4. "Mark all as read" in the list's nav bar.
5. Opening a Match that was since deleted shows "This Match is no longer available".
6. "Find similar Matches" opens Discover filtered to the same sport.
7. Notifications are never shown to anyone but the recipient (D38).
