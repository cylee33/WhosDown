## Goal

A new Player picks their sports and a level for each, fills in a basic profile, allows location, saves notification preferences, and lands on Discover.

## Screens

Order: H03 → H42 → H04 → H05 → H44.

| Screen | What this feature owns on it |
|---|---|
| H03 Select your sports | Grid of nine sports plus "Other"; multi-select; "Other" asks for a custom name; "Next" |
| H42 Set skill levels | One row per chosen sport with levels Beginner, Casual, All Levels, Intermediate, Competitive; helper text "These help recommendations only — they don't restrict what you can join."; "Continue" |
| H04 Complete profile | Photo (initials until added), play style chips (Social / casual, Competitive, Learning), bio, home area, "Finish setup". The wireframe's "Soccer level" block is left out: H42 already sets levels |
| H05 Stay in the loop | Location: "Allow while using app" / "Not now". Notification preferences chips: Approvals, Time/location, Cancellations (all on by default); "Continue", which shows the iOS notification permission prompt once (for 1.24 reminders) |
| H44 You're all set! | Summary line (sports · home area · level · notifications), "Find Matches" |

## Data

| ID | Read / write | Path and fields |
|---|---|---|
| W1 (update) | write | `users/{uid}`: `sportLevels` (map sport → level), `customSportName` (if Other), `playStyles`, `bio`, `homeArea`, `photoURL`, `onboardedAt` |
| W16 | write | `users/{uid}/private/settings.notificationPrefs`: `approvals`, `timeOrLocationChanges`, `cancellations` |
| Storage | write | `users/{uid}/avatar.jpg` → download URL saved to `photoURL` |
| Core Location | — | When-in-use permission request |
| UserNotifications | — | `requestAuthorization(options: [.alert, .sound, .badge])` on H05 "Continue" |

**Security rules this feature needs:** only the owner updates their profile; `bio` ≤ 300 characters, `homeArea` ≤ 60, `displayName` 1–40. Storage: only the owner writes `users/{uid}/avatar.jpg`, image types only, ≤ 5 MB.

## Rules and edge cases

1. H03 needs at least one sport selected to continue.
2. "Other" asks for a name (1–30 characters). One custom sport per Player in V1.
3. H42 needs a level for every chosen sport; default selection is All Levels.
4. Photo is optional. Resize to 512 px square JPEG before upload. Without a photo, show initials from the display name.
5. Play style, bio, and home area are optional.
6. Location "Not now" is allowed; Discover then centers on CMU (40.4433, −79.9436) and shows a "Turn on location" hint.
7. Tapping "Continue" on H05 asks iOS for notification permission once, so Match reminders (1.24) are on by default. Notification preferences are only **saved** in V1. In-app notifications always arrive, and push is V2, so these switches take effect in V2.
8. Profile and settings are saved together at "Finish setup" and H05 "Continue". If the app is closed partway, the Player resumes at the first unfinished step (`onboardedAt` stays null until H44).
9. "Find Matches" opens Discover. If onboarding started from the Guest gate (1.3), return to that screen instead.
10. Back navigation keeps earlier choices.
