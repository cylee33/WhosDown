## Goal

A Player can back out at any time before the Match starts: leave an approved spot, cancel a pending request, or leave the waitlist. They confirm first, and the counts update for everyone.

**Security rules this feature needs:** a Player can set their own RSVP to `left` from approved, pending, or waitlisted, with exactly the matching counter going down by 1. The Host can't leave (D25).

## Rules and edge cases

1. The button matches the status: "Leave Match" (approved), "Cancel request" (pending), "Leave waitlist" (waitlisted).
2. Always confirm with a bottom sheet (1.26).
3. Allowed until the Match starts. After the start, the buttons are hidden.
4. **The Host has no Leave button.** Their options are Cancel Match or Transfer host (D25, 1.18, 1.28).
5. After leaving, the screen returns to H09 with the join button available again (if there's a spot).
6. Leaving removes the 1-hour reminder (1.24). A calendar event the Player added stays; it's in their own calendar.
7. Leaving the chat: a Player who left loses access to Match chat (D39).
8. No notification to the Host in V1 when someone leaves (the count changes live on H20).
