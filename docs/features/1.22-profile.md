## Goal

A Player sees their own profile organized by sport, edits it, and can look at any other Player's profile, including a Host's.

## Rules and edge cases

1. Own profile is the Profile tab; others' profiles open from H09's Host row and H11's rows.
2. Sports are listed one per row with that sport's level (the feature's "organized by sport").
3. "N Matches played" = number of checked-in Matches the Player attended.
4. Save validates as in 1.4 (name 1–40, bio ≤ 300, home area ≤ 60) and is disabled until something changed.
5. Removing all sports isn't allowed (at least one).
6. Name changes don't rewrite old copies (RSVPs, chat messages, `hostName`); new ones use the new name. A V2 Cloud Function can fix old copies.
7. Viewing your own profile through H10 shows H36 instead.
