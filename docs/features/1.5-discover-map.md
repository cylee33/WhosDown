## Goal

A Player opens Discover and sees nearby Matches as sport pins on a map around them. They tap a pin to preview it, and see their next Match at the top.

## Screens

| Screen | What this feature owns on it |
|---|---|
| H06 Discover map | Nav title "WhosDown"; "Next up" card; Map/List toggle; MapKit map with user dot, radius circle, sport pins; pin card (sport icon, title, time · distance, level chip, joined/limit, price) |

Hide the search icon (Search is V2, 2.3). The top-right menu icon opens Filters (1.7).

## Data

| ID | Read / write | Path and fields |
|---|---|---|
| R1 | read | `matches` where `geohash` in the ranges covering center + radius, `status == "scheduled"`; then exact distance on the device, and keep only Matches whose `endTime` is in the future |
| R5 | read | Collection group `rsvps` where `userId == me`, `status == "approved"`; parent Matches fetched by ID; the earliest upcoming is "Next up" |
| R8 | read | `users/{me}/private/settings.searchRadiusMiles` (default 3) |
| MapKit | — | Map, user location, `CLLocation.distance(from:)` |

**Indexes:** `matches` (`status`, `geohash`); collection group `rsvps` (`userId`, `status`).

## Rules and edge cases

1. The map centers on the Player's location; without permission, on CMU (40.4433, −79.9436) with a "Turn on location" hint.
2. The radius circle uses the saved search radius (1.7 changes it).
3. One pin per Venue; if several Matches share a Venue, the pin shows a count and its card lists them.
4. Pins show the sport's icon; Full Matches show a muted pin.
5. Tapping a pin shows the card; tapping the card opens Match details (1.8).
6. "Next up" shows the Player's next approved Match (title · time, Venue, status). Tapping it opens that Match. Hidden if there's none, and for Guests.
7. **Search follows the map.** When the Player pans or zooms, R1 re-runs around the new map center once the map has stopped moving for 0.5 seconds, and only if the center moved more than a quarter of the radius. The radius circle moves with the center. A "Back to my location" button recenters.
8. Matches that started but haven't ended still show (labelled "Now").
9. Empty result: "No Matches nearby yet. Try a bigger radius or host one." with a button to Create.
10. Results refresh when the screen appears and on pull-to-refresh in the list.
