## Goal

Everyone going to a Match, and its Host, can talk in one live chat for that Match.

## Data

| ID | Read / write | Path and fields |
|---|---|---|
| R13 | read (listener) | `conversations/{matchId}/messages` ordered by `sentAt`, last 50; older pages on scroll |
| W11 | write (batch) | New `messages/{id}`: `senderId`, `senderName`, `text`, `sentAt` (server time); `conversations/{matchId}.lastMessageText`, `lastMessageAt` |

**Security rules this feature needs (D39):** read and create only if `auth.uid` is the Match's Host or has an `approved` RSVP; `senderId == auth.uid`; `text` 1–1000 characters; no edits or deletes in V1.

## Rules and edge cases

1. Only approved Players and the Host can open the chat. Pending, waitlisted, declined, left, and Guests can't.
2. A Player who leaves loses access right away.
3. Chat stays open after the Match ends or is cancelled (D39).
4. The "Host" label follows `matches.hostId`. After a transfer it moves to the new Host (D33), with no write needed.
5. Messages appear live; sending shows the message at once (pending style) and confirms when saved.
6. Text is trimmed; empty messages can't be sent.
7. Scroll starts at the newest message; older ones load when scrolling to the top.
8. Entry points: "Open Match chat" and "Chat" on H14, the chat row on H20, "Open Match chat" on H51.
9. New-message notifications are V2 (H54).
