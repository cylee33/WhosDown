## Goal

The Host fixes details of an upcoming Match, and Players are told what changed. Or the Host cancels it with a reason, and everyone with an RSVP is told.

## Screens

| Screen | What this feature owns on it |
|---|---|
| H46 Edit Match | Date; start / end; location (H40); player limit; join type; description; "Notify joined Players about these changes" switch (on); "Save changes" |
| H38 Cancel confirmation | Bottom sheet: "Cancel this Match?", "Everyone will be notified immediately."; "Before canceling" note; "Transfer host instead" (1.28); reason field; "Cancel Match" (red) |

## Data

| ID | Read / write | Path and fields |
|---|---|---|
| W4 | write (batch) | Update `matches/{id}` changed fields (and `geohash`, Venue facts if location changed) + `updatedAt`; if notify is on: one `matchUpdated` notification per approved Player with `changes: [{field, oldValue, newValue}]` and optional `hostNote` |
| W5 | write (batch) | `matches/{id}.status = "cancelled"`, `cancelReason`; one `matchCancelled` notification per RSVP that is approved, pending, or waitlisted |

**Security rules this feature needs:** only the Host updates a Match; `hostId`, counters, and `createdAt` can't be changed by an edit; `playerLimit ≥ joinedCount`; edits and cancel only before `startTime`; a cancelled Match can't be edited or un-cancelled.

## Rules and edge cases

1. Edit and Cancel are only available before the Match starts.
2. **Player limit** can't be set below the joined count; the field explains "12 Players have joined" (D24). Raising it while the waitlist has people offers the new spots (1.17).
3. **Join type Open → Approval required:** joined Players stay joined.
4. **Join type Approval required → Open:** see Open questions.
5. Location change goes through H40 and updates `venueName`, `location`, `geohash`, and Venue facts.
6. Notify switch on: one notification per approved Player listing every changed field ("Time: 7:00 PM → 7:30 PM"). Off: no notifications; the changes still show live.
7. Description edits alone don't notify, even with the switch on.
8. Reminders (1.24) move with a time change on each Player's device.
9. **Cancel** needs a reason (1–200 characters), shown to Players on H09 and H52.
10. After cancel: the Match leaves Discover, H09 shows the cancelled banner, chat stays readable (D39), reminders are removed (1.24).
11. "Transfer host instead" closes the sheet and opens H22 (1.28).
