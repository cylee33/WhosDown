## 1. Goal

We tested the high-fidelity interactive prototype (Figma, 63 screens, H01–H63) to check whether players can find, evaluate, and join a game, and whether hosts can create and manage one, without help. We also wanted to know which features players need in Version 1 and which can wait for Version 2.
